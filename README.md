# EHR-Health

A small electronic health records (EHR) system built with **Laravel 10**. Staff can admit patients, place them in hospital beds, assign doctors and nurses, and discharge patients **without losing their history**.

> **Demo data only.** Every patient, doctor and nurse is randomly generated by Faker. Don't enter real medical information.

## What it does

- **Admission:** a new patient is placed in the first free bed and an admission record is opened. If no bed is free, admission is refused.
- **Beds:** move patients between free beds, free a bed without discharging, and see ward occupancy on the dashboard. A bed can never be double-booked.
- **Care teams:** assign doctors (with a condition and date) and nurses to admitted patients. Assignments keep their start and end dates.
- **Discharge, not delete:** discharging closes the admission, frees the bed and ends active assignments. The patient record is kept for history.
- **Dashboard:** admitted patients, free beds, overall occupancy and per-ward usage.
- **Access control:** every page except the home page sits behind a staff login (HTTP Basic, credentials in `.env`).

## How it is built

| Piece | Where |
| --- | --- |
| Business rules (admit, bed moves, assignments, discharge) | `app/Services/PatientFlow.php`, all multi-table changes run in database transactions |
| Validation | Form Request classes in `app/Http/Requests` |
| Models and relationships | `app/Models` (patients, doctors, nurses, wards, beds, patient records) |
| Staff login | `app/Http/Middleware/StaffOnly.php`, configured in `config/ehr.php` |
| Demo data | factories and seeders in `database/`; the seeder uses the same service as the app, so the data is always consistent |
| Tests | `tests/Feature`, 34 tests covering admission, discharge, beds, care teams, access control and the dashboard |

Design decisions worth knowing:

- Patient history is never destroyed. Doctors, nurses and beds with history can't be deleted.
- A bed's `occupied` flag and `patient_id` are always changed together, inside one transaction.
- Open admissions are the source of truth for "currently admitted" (`date_of_release IS NULL`).

## Setup

Requires PHP 8.1+ and Composer.

```bash
git clone https://github.com/KrishnaClarke/ehr-lar.git
cd ehr-lar
composer install
cp .env.example .env
php artisan key:generate
```

Edit `.env`: set `ADMIN_USER` and `ADMIN_PASSWORD`, and choose a database.

**MySQL** (default): create a database named `ehr_laravel` and set `DB_USERNAME` and `DB_PASSWORD`.

**SQLite** (zero setup): set `DB_CONNECTION=sqlite`, remove the other `DB_*` lines, then run `touch database/database.sqlite`.

Then:

```bash
php artisan migrate --seed
php artisan serve
```

Open http://localhost:8000, then go to the dashboard and sign in with your `ADMIN_USER` / `ADMIN_PASSWORD`.

## Tests

```bash
php artisan test
```

Tests use an in-memory SQLite database and run automatically on every push through GitHub Actions.
